MeGa AI - النسخة الأولية

هذه واجهة عربية متجاوبة بتصميم أسود وذهبي.
لفتحها: ارفع الملفات إلى استضافة مواقع ثابتة تدعم HTTPS، أو شغل خادم محلي داخل المجلد.

الموجود الآن: واجهة المحادثة، تصميم الهاتف والكمبيوتر، اقتراحات جاهزة، محادثة جديدة.
غير الموجود بعد: اتصال حقيقي بنموذج AI، حسابات المستخدمين، حفظ المحادثات، رفع الصور والفيديو، الاشتراكات.

الخطوة التالية: إضافة Backend آمن وربطه بمزود الذكاء الاصطناعي. لا تضع مفتاح API داخل ملفات الواجهة أو المتصفح.
